## LocDrop demo page

The portfolio's QR code points to this repo's GitHub Pages site:
**https://christohartanto.github.io/LocDrop-demo/**

That address never changes, so the printed QR code keeps working even when the app moves.

### How to change the demo link

1. Open `index.html` on github.com and click the pencil icon (Edit).
2. Find the line under `TO CHANGE THE DEMO LINK` and replace the address inside `href="..."`.
3. Click **Commit changes**. The page updates within about a minute.

Also update the link at the top of this README so the two match.
